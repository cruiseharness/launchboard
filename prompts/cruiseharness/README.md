# Cruise Harness: the ten submitted prompts

These are the exact work prompts shown in [When we put Codex on cruise control for 10 prompts](https://cruiseharness.com/blog/when-we-put-codex-on-cruise-control-for-10-prompts), in submission order. Each prompt file contains only the submitted text, ready to copy.

These are the record of that run, rather than a prescribed sequence for another harness: the [challenge](../../README.md#try-your-harness) asks your harness to choose its own follow-ups.
